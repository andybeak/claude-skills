Surface the hidden assumptions behind $ARGUMENTS (or, if empty, the plan/claim currently under discussion):

1. List the assumptions being made, including ones treated as too obvious to state.
2. For each, note what would have to be true for it to hold, and how confident that actually is.
3. Rank them by how likely they are to be wrong AND how much damage it does if they are.
4. Flag any assumption nobody has actually verified yet.

Skip assumptions that are trivially true — this is about the ones actually load-bearing and shaky.
